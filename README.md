# СMDB
 
Программа является СУБД для работы с техникой и пользователями.
В данной программе есть 6 различных действий:
1. Движение
Данное действие меняет владельца объекта,а также создает в таблицу с историей запись о переносе объекта.
2. Техника
Данное действие позволяет посмотреть свойства техники, ее владельца///
