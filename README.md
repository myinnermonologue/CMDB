# СMDB
 
Программа является СУБД для работы с техникой и пользователями.
В данной программе есть 6 различных действий:
1. Движение
Данное действие меняет владельца объекта,а также создает в таблицу с историей запись о переносе объекта.
2. Техника
Данное действие позволяет посмотреть свойства техники, ее владельца, а также остальные характеристики.
3. Склад
Позволяет посмотреть какая техника присутствует на складе и экспортировать в .xlsx.
4. Сотрудник
Позволяет посмотреть все характеристики конкретного сотрудника,а также технику, которой он владеет, и историю изменений сотрудника(статус и т.д.)
